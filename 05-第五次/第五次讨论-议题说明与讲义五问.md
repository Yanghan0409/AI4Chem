## 一、议题说明

### 本周主题：从 LLM 对话到 Agent

**核心问题：如何将大语言模型组织成能够调用工具、根据反馈推进任务的 Agent 系统？**

前三次讨论了计算机、数据与信息，第四次认识了机器学习与神经网络。这次从大家接触过的大语言模型（Large Language Model，LLM）与相关应用出发，梳理对话、提示词工程、资料检索、Skills 和 Harness，了解它们分别解决什么问题，并认识市场上的模型与 Agent 产品。

本次术语约定：LLM 指底层模型；LLM Agent 指由模型参与决定下一步行动、通过工具与环境交互并根据反馈推进任务的系统，下文简称 Agent；Skills 指可按需加载的任务指令、脚本与资源包；Harness 指支撑模型与工具执行循环、上下文和状态管理等过程的运行软件。Skills 与 Harness 均属于系统层面的组织与实现，不等同于模型本身的能力，也不保证结果正确。

本次以 2023 年以来的使用方式变化为线索，但这些技术的发展相互交织，并非严格的先后替代关系。重点是理解每种方法的用途，结合自己的研究举例。CLI（命令行入口）与 MCP（工具和数据连接协议）作为补充概念，了解作用即可，暂不要求配置。

原定的 LogP 性质预测练手项目保留为后续实践方向，本次先为使用 Agent 辅助项目做准备。

## 二、讲义五问

> 每人任选一问准备一页材料，尽量用一个具体例子说明；分享不超过 3 分钟。

### 1. 发展：LLM 的使用方式发生了什么变化？

从对话与提示词工程，到工具调用与 Agent 系统，任务的执行方式发生了什么变化？

### 2. 依据：Agent 怎样检索资料、核查回答？

什么是检索增强生成（RAG）？Agent 如何通过知识库、联网搜索或本地文件检索获取资料，并核查回答是否得到来源支持？

> 概念提示：RAG 是利用检索结果辅助生成的方法，不限定使用向量数据库；联网搜索和文件检索是获取资料的具体方式，可成为 RAG 或 Agent 工作过程的一部分。检索到资料不等于回答正确，仍需检查来源、引用和推论。

### 3. Skills：Agent 怎样复用专业方法？

什么是 Skills？它与每次重新写提示词有什么区别？结合自己的研究，举一个可以封装成 Skill 的任务。

### 4. Harness：怎样支持 Agent 持续完成任务？

什么是 Harness？它怎样帮助 Agent 管理任务进度、检查结果，并在出错后继续工作？

### 5. 市场：现在有哪些大语言模型与 Agent 产品？

GPT、Claude、Gemini、DeepSeek、Qwen、Kimi 等模型家族，与 Codex、Claude Code、Cursor、Manus 等 Agent 产品处于什么层次？选一个你感兴趣的产品，介绍它能做什么。

> 市场认识提示：先区分底层模型、成品 Agent 与搭建平台。Agent 产品把模型、资料、工具和执行机制组织起来；Dify、扣子等平台用于搭建自己的应用与工作流。同一品牌可能同时指模型家族与应用，分享时需说明具体对象。产品功能与模型版本变化较快，分享时标明查阅日期与官方来源，不要求背版本号或排名。

## 三、实践与验收（独立任务）

### 实践

选择一种 Agent 工具，完成一个与你学习或科研有关的小任务，例如：

- 整理几篇论文的研究对象、方法和主要结论，并保留出处；
- 处理一份数据，生成图表并检查数值；
- 编写并运行一段分析脚本，检查输出是否符合要求。

任务以能在课前完成、结果可以检查为宜，使用现有工具即可，不要求自行搭建 Agent。

### 提交

概念讨论与实践分别准备一页 PPT/PDF。实践页展示任务要求、使用的工具、完成结果，以及人工检查中发现的问题；如任务没有完成，也可以展示卡点和已完成的步骤。

- 概念页命名：`<姓名> - 从LLM对话到Agent.pptx/pdf`；
- 实践页命名：`<姓名> - Agent实践.pptx/pdf`；
- 提交到仓库 `05-第五次/` 目录，必要时附上可核查的结果文件。

### 验收

- 能说明 Agent 实际执行了哪些操作；
- 至少核查一项关键结果，如文献出处、数据、计算或代码输出；
- 判断任务是否完成，并说明哪些地方仍需人工处理。

## 五、入门参考

以下为准备时可选的官方资料，无需全部阅读。英文资料可用大语言模型辅助理解，分享前需核对原文。
